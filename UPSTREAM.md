# Upstream practice reference

This starter is an original local adaptation informed by
[`taclab-research/science-repo-practices`](https://github.com/taclab-research/science-repo-practices),
an Apache-2.0 repository describing reproducible ML-adjacent project practices.

The local starter adopts the same broad direction—uv, a `src` layout, Ruff, basedpyright, pytest,
pre-commit, CI, structured configuration, and explicit data/output hygiene—while keeping a smaller
typed TOML runtime and a runnable provenance example. Consult the upstream repository when evolving
the template; do not assume this snapshot tracks every future upstream recommendation.
